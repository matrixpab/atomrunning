# ATOM RUNNING CLUB · Plataforma Web Oficial

Plataforma digital deportiva de alto rendimiento para **ATOM RUNNING CLUB**, comunidad y equipo de entrenamiento de running y trail dirigido por el **Prof. César Vergel** en La Dormida (Santa Rosa) y La Paz, Mendoza, Argentina.

---

## ⚡ Características Principales

- **Hero Cinematográfico con Video 16:9:**
  Loops de video en alta definición (1080p) con doble codificación (`WebM VP9` + `MP4 H.264`), poster images en `WebP`, lazy-playback mediante `IntersectionObserver` y soporte para `prefers-reduced-motion`.
- **Cobertura Editorial de Grandes Competencias:**
  - **Potrero Corre 2026 (San Luis):** Crónica completa de la 9ª edición, distancias 22K, 12K y 6K en el Circuito Internacional de Boxes, trofeo al equipo más numeroso y galería con 9 fotografías reales.
  - **Media Maratón de Buenos Aires 2026:** Crónica de la travesía de 21 Kilómetros en Palermo, tiempos oficiales y galería exclusiva de 13 fotografías.
- **Identidad de Marca & Logos Oficiales:**
  Isotipos vectoriales SVG en Ultra HD de **WhatsApp Oficial**, **Instagram Oficial** y el escudo deportivo **ATOM RUNNING**.
- **Metodología de Entrenamiento & Sedes:**
  Información técnica sobre pasadas, fondo, técnica de carrera y fuerza funcional con horarios y circuitos en La Dormida y La Paz.
- **Galerías Fotográficas & Lightbox:**
  Visualizador interactivo tipo masonry con filtrado dinámico por categorías (largada, carrera, podios, equipo) y navegación por teclado/táctil.
- **Herramientas de Gestión:**
  - `admin.html`: Panel Administrador (CMS) para edición de datos del club.
  - `marketing.html`: Centro de recursos, guiones para reels y calendario editorial.

---

## 🚀 Tecnologías

- **HTML5 Semántico** & **CSS3 Moderno** (variables CSS, flexbox, CSS Grid).
- **JavaScript ES6+** vanilla reactivo sin dependencias pesadas.
- **Vite** para desarrollo ágil y bundling ultra rápido.
- **Lucide Icons** & **SVG Vectorial Nativo**.

## 📦 Instalación y Desarrollo Local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/matrixpab/atomrunning.git
   cd atomrunning
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor local:
   ```bash
   npm run dev
   ```
   Abrir [http://localhost:5173/](http://localhost:5173/) en el navegador.

4. Compilar para producción:
   ```bash
   npm run build
   ```
